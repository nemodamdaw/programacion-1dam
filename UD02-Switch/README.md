# UD02-Switch — Soluciones de Programación UD2

Proyecto Java importable en Eclipse, con 4 clases ejecutables dentro de `src/ejercicioXX`.
Cada clase tiene su propio método `main` para ejecutar por separado.

Los enunciados originales están en `docs/`. No deben editarse para conservar la referencia.

## Uso
1. File > Import > General > Existing Projects into Workspace.
2. Seleccionar el directorio que contiene los proyectos y marcar este proyecto.
3. Abrir `src/ejercicio01/Ejercicio01.java` y usar Run As > Java Application.

Soluciones didácticas: estructuras solicitadas por el boletín, bucles clásicos y condiciones explícitas.
Los ejercicios numéricos incluyen comprobaciones de rangos y casos sin datos cuando es necesario.
